# AI for Differentiated Learning - Logarithms Assignment Report

## Project Overview
This web application leverages AI-driven prompt structures to adapt the core mathematical topic "Logarithms and Their Properties" (Логарифмдер және олардың қасиеттері) into 3 distinct difficulty tiers for differentiated learning.

## Differentiation Levels
1. **Level 1 (Foundation):** Simplified context, direct conceptual definitions, and step-by-step guided breakdown for struggling learners.
2. **Level 2 (Standard):** Standard grade-level curriculum problem-solving focusing on fundamental logarithm properties and operations.
3. **Level 3 (Advanced):** Multi-step logarithmic equations and logic challenges connecting algebraic properties.

## AI Prompt Engineering Strategy
The AI component is designed using system prompts that instruct the LLM to adjust cognitive load, scaffold hints dynamically, and provide targeted feedback based on the selected tier.
